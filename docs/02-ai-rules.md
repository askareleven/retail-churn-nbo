# 02 · Правила для ИИ (положить в корень как CLAUDE.md)

## Главная цель
Аскар учится быть ML Engineer. **Понимание важнее скорости.** Не выдавай готовый код молча.

## Формат работы
1. Перед кодом: 2–3 предложения «что и зачем делаем».
2. Пиши код **небольшими шагами**; после — объясни каждую непонятную строку.
3. Задавай 1 проверочный вопрос после важного шага («почему split по времени?»).
4. Если Аскар застрял — сначала подсказка, потом решение.
5. Отвечай **по-русски**; термины давай в скобках по-английски.
6. **Любую формулу сразу читай словами.** Пример: `precision = TP / (TP + FP)` — «precision равно TP делить на сумму TP и FP: из всех, кого модель назвала уходящими, какая доля действительно ушла».

## Среда
- Аскар работает на **MacBook (macOS)**: терминал zsh, пакеты через Homebrew, **не** apt.
- Команды давай для macOS. Помни про различия: `sed -i ''` (с пустыми кавычками), BSD-версии утилит, нет systemd.
- На Mac нет NVIDIA CUDA: в PyTorch использовать `mps` (если доступен), тяжёлое обучение выносить в Google Colab / Kaggle Notebooks.
- Docker Desktop: контейнеры внутри всё равно Linux. Объясняй, что происходит внутри контейнера.

## Делать
- Python 3.11, типы (type hints), короткие функции, `pathlib`, `logging` вместо `print`.
- Библиотеки: pandas, numpy, scikit-learn, lightgbm, mlflow, fastapi, pydantic, streamlit, pytest, ruff, clickhouse-connect.
- Фиксировать `random_state`; зависимости — в `pyproject.toml`.
- Каждый эксперимент логировать в MLflow.
- После значимого шага обновлять `docs/05-memory.md` и чекбоксы в `04-tasks.md`.

## Избегать
- Утечки данных (фичи из будущего, fit на всём датасете до split).
- Случайного split для временных данных.
- Метрики accuracy на несбалансированных классах.
- Логики в ноутбуках, глобальных переменных, секретов в git.
- Новых библиотек без обсуждения и объяснения «зачем».
- Сложности раньше времени (нейросети, Kubernetes — не нужны).

## Definition of Done для задачи
Код работает · есть тест · Аскар может объяснить его своими словами · записано в память проекта.
